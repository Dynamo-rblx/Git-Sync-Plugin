GitSync is a free, open-source Roblox plugin. It allows scripters, aspiring scripters, and script users to store their work on an easily accessible cloud-based GitHub repository!

The plugin enables Roblox developers to upload and update scripts via **push**, import remote repository directories or overwrite selected scripts via **pull**, **browse** remote repository files, and create and work with **branches**. If you're curious about the specifics, you can check out the pages under the <button class="nav-guide" style="color: var(--theme-accent);" data-highlight-pages="pushing pulling branches repository-viewer">Features</button> section in the navigation bar.

Rather than serializing builds, GitSync retrieves only the scripts, maintains their ancestry through directory structure, and handles pulling the way you'd expect if the path still exists. If the path doesn't exist, the plugin will just make folders instead. Still, storing other instances in a reasonable way is a goal that continues to be considered as updates continue
