## How to Contribute

Find a problem and make a pull request. Or, report an issue so that somebody else can solve it.

Learn about creating PRs here: [https://docs.github.com/en/pull-requests/how-tos/create-pull-requests/creating-a-pull-request](https://docs.github.com/en/pull-requests/how-tos/create-pull-requests/creating-a-pull-request)

Learn about creating Issues here: [https://docs.github.com/en/issues/tracking-your-work-with-issues/using-issues/creating-an-issue](https://docs.github.com/en/issues/tracking-your-work-with-issues/using-issues/creating-an-issue)
